# تفعيل DeepSeek بأمان

تعمل ميزات الذكاء الاصطناعي من خلال وظيفة Supabase باسم `ai-assist`. لا يظهر مفتاح DeepSeek في المتصفح، ولا يُحفظ في GitHub أو في ملفات المشروع.

## مكان وضع المفتاح بعد رفع المشروع

افتح مشروع Supabase المرتبط بالموقع، ثم انتقل إلى:

> **Project Settings → Edge Functions → Secrets**

أضف الأسرار التالية:

| الاسم              | القيمة                                                | مطلوب                                     |
| ------------------ | ----------------------------------------------------- | ----------------------------------------- |
| `DEEPSEEK_API_KEY` | مفتاح DeepSeek الذي يبدأ بـ `sk-`                     | نعم                                       |
| `DEEPSEEK_MODEL`   | `deepseek-flash`                                      | اختياري؛ هذه هي القيمة الافتراضية         |
| `DEEPSEEK_USER_ID` | معرّف DeepSeek أو معرّف المؤسسة المقدم من مالك الحساب | اختياري؛ يمرر للـ API كمُعرّف استخدام فقط |

لا تضع المفتاح في ملف `.env` المرفوع إلى GitHub، ولا في أي ملف TypeScript، ولا داخل إعدادات الواجهة. إذا ظهر المفتاح في مكان عام، ألغِه من منصة DeepSeek وأنشئ مفتاحاً جديداً فوراً.

## النشر المطلوب في Supabase

بعد رفع هذه النسخة إلى GitHub، طبّق Migration الموجود في:

```text
supabase/migrations/20260918194000_feedback_and_ai.sql
```

ثم انشر وظيفة Edge Function الموجودة في:

```text
supabase/functions/ai-assist/index.ts
```

## ما الذي يفعله المساعد

| الموضع                        | الوظيفة                                                                  |
| ----------------------------- | ------------------------------------------------------------------------ |
| جميع نماذج السجلات والمستندات | تحسين مسودة الحقول النصية قبل الحفظ، مع بقاء القرار والتحرير للمستخدم    |
| استيراد السجلات العام         | مراجعة عناوين الأعمدة واقتراح ربطها بالحقول قبل الاستيراد                |
| استيراد الطلاب                | مراجعة عناوين الملف واقتراح التوزيع؛ لا تُرسل بيانات الصفوف إلى DeepSeek |
| الآراء والرسائل               | تلخيص الرد وتصنيفه واقتراح إجراء متابعة                                  |
| التوجيه الطلابي الأسبوعي      | إعداد التمهيد والرسالة الإرشادية والتذكير الختامي                        |

## الخصوصية

تقوم الوظيفة بحجب أرقام الهوية والجوالات والعناوين والبريد الإلكتروني قبل إرسال النص إلى DeepSeek. لا تستخدم المساعدة الذكية لطلب تشخيصات صحية أو نفسية أو لاتخاذ قرارات آلية بحق الطلاب.
