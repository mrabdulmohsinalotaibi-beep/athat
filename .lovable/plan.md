# تحديثات: استيراد ذكي، طباعة رسمية للسجل الفردي، مرفقات، وتطوير الإحالات

## 1) استيراد ذكي بالذكاء الاصطناعي
- إضافة زر «تعيين الأعمدة بالذكاء الاصطناعي» داخل نافذة استيراد الطلاب (نور) وفي استيراد Excel لباقي السجلات.
- يُرسل عناوين الأعمدة وعينة من الصفوف إلى مساعد الذكاء الاصطناعي، فيعيد تعييناً مقترحاً لكل حقل (اسم الطالب، السجل المدني، الصف، الفصل، ولي الأمر، الجوال، الملاحظات، الحالة) مع تجاهل الأعمدة غير المناسبة.
- التعيين المقترح يظهر في نفس شاشة المعاينة ويمكن تعديله يدوياً قبل الحفظ؛ الحقول الناقصة القابلة للاستنتاج (مثل الحالة «نشط» أو المرحلة من الصف) تُكمَّل تلقائياً.

## 2) طباعة رسمية / PDF لكل سجل فردي
- زر «طباعة رسمية / PDF» بجانب كل صف في جميع السجلات (حالة، مقابلة، سلوك، مواظبة، إحالة، اجتماع، مهمة...).
- يفتح ورقة رسمية بيضاء: كليشة الوزارة والشعار، عنوان السجل، جدول تفاصيل كامل للحقول المعبأة، ملخص الحالة، ثم خانتا توقيع الموجه الطلابي ومدير المدرسة مع الحقوق.
- من نفس النافذة: طباعة مباشرة أو تصدير PDF بمقاس A4.

## 3) مسح الاختيار
- زر (×) واضح داخل مربع اختيار الطالب وداخل القوائم المنسدلة في النماذج لإفراغ القيمة فوراً.
- زر مسح لحقل البحث في أعلى كل سجل.

## 4) مرفقات داخل السجلات
- لوحة مرفقات داخل كل سجل: رفع صور وPDF ومستندات مباشرة، مع عرض مصغّرات وأسماء الملفات.
- معاينة داخل المنصة، وتحميل، وحذف للمرفق مع ملفه.
- ربط المرفق بالسجل بمعرّف ثابت حتى تبقى المرفقات ظاهرة بعد أي تعديل.

## 5) تطوير قسم الإحالات
- مساعد ذكي داخل نموذج الإحالة يولّد سبب الإحالة، الإجراءات السابقة، والتوصيات بضغطة واحدة.
- توسيع «الجهة المحال إليها» لتشمل جهات داخلية (إدارة المدرسة، وكيل شؤون الطلاب، لجنة التوجيه الطلابي، المعلم، المرشد الصحي) بجانب الجهات الخارجية الحالية، مع حقل «نوع الإحالة: داخلية/خارجية».
- زر «مشاركة عبر واتساب» يفتح رسالة منسقة تتضمن بيانات الطالب وسبب الإحالة والتوصيات، مع إمكانية إدخال رقم الجهة المستقبِلة، وخيار تصدير ورقة الإحالة الرسمية PDF قبل الإرسال.
