# Guidance Hub

قم ببناء منصة وتطبيق ويب تفاعلي شامل للموجه الطلابي (باسم 'ذات' أو 'منصة الموجه الطلابي') متوافق مع متطلبات وزارة التعليم السعودية ونظام نور، معتمداً على ملف الإكسل المرفق 'ذات_THAT_ملف_شامل_اعمال_الموجه_الطلابي.xlsx'.

المميزات الأساسية للمنصة:
1. لوحة تحكم (Dashboard) عصرية وشاملة:
   - إحصائيات سريعة: إجمالي الطلاب، الحالات الإرشادية النشطة، غياب ومواظبة اليوم، المقابلات المجدولة، المخالفات السلوكية، البرامج المنفذة.
   - تنبيهات ومتابعات عاجلة، ومخططات بيانية لمؤشرات الأداء الإرشادي.
   - معلومات المدرسة في الترويسة (اسم المدرسة، إدارة التعليم، مكتب التعليم، مدير المدرسة، اسم الموجه الطلابي، العام والفصل الدراسي).

2. السجلات الإرشادية اليومية والشاملة (مأخوذة من شيتات الملف المرفق):
   - سجل الطلاب: بيانات الطالب، الهوية، الفصل، جوال ولي الأمر، السكن، الحالة الصحية/الاجتماعية.
   - استيراد تقارير نظام نور: إمكانية رفع وتغذية الطلاب آلياً من ملفات إكسل أو جداول نور.
   - الحالات الإرشادية: دراسة حالة، متابعة فردية، نوع الحالة (تحصيلي، سلوكي، اجتماعي، نفسي، صحي)، خطة التدخل وتاريخ المتابعة.
   - الخطة التشغيلية والبرامج الإرشادية: الأهداف، البرامج والأنشطة، الفئة المستهدفة، زمن التنفيذ، مؤشرات التحقق.
   - سجل المقابلات والتواصل: مقابلات الطلاب، أولياء الأمور، المعلمين، وسائل التواصل ونتائج المقابلة.
   - الحضور والمواظبة ورصد السلوك: رصد التأخر والغياب والمخالفات السلوكية وفق قواعد السلوك والمواظبة المعتمدة مع الإجراءات المتخذة.
   - سجل الإحالات: إحالة إلى وحدة الرعاية الطلابية أو جهات خارجية مع نماذج المتابعة.
   - اللجان والاجتماعات: لجنة التوجيه الطلابي، محاضر الاجتماعات، التوصيات والقرارات.
   - الشواهد والتوثيق: رفع صور ومستندات توثيق الأنشطة والبرامج.

3. الاستيراد والتصدير والطباعة:
   - تصدير كافة السجلات والتقارير بصيغة PDF مهيأة للطباعة الرسمية مع ترويسة الوزارة وتوقيع الموجه ومدير المدرسة.
   - إمكانية تصدير واستيراد البيانات عبر Excel.

4. واجهة استخدام وتصميم:
   - تصميم حديث يدعم اللغة العربية بالكامل (RTL) بهوية تعليمية راقية ومريحة للعمل اليومي.
   - تجربة مستخدم سلسة وشبيهة بتطبيقات الويب الحديثة (Web App) مع شاشة تسجيل دخول (بالبريد أو Google) وإعدادات تخصيص بيانات المدرسة.
